Design mockup only, drawn at 1920x1080. The box really draws at 1280x720 (see BOX-FACTS.md) and the TV stretches that 1.5x, so the "real box size" button shows the exact pixel count the box has (best judged on a normal, non-retina screen). Wallpapers, card art, logos, box art and the QR code are code-drawn placeholders, not final art: real channel logos, thumbnails and box art come from the box at run time. Glass here uses the browser's live blur; on the box it is a pre-blurred copy of the wallpaper (Android 7 has no live blur).
